Run any web-based LOS side-by-side with a companion app you control

LOS Companion is a free Electron desktop template for developers whose LOS is a closed system by design — no public API, no interconnectivity, no vendor approval process. Copy the template, point it at your LOS, and build the integrations your vendor never shipped — with full Node.js power next to the app, not trapped behind browser CORS and CSP.

Built for closed LOS platforms

No API? No problem.

Works with LOS platforms that have little or no interconnectivity. The app observes what the page already exposes — URL structure and localStorage — and injects its own UI. No vendor keys, no integration approvals.

CORS and CSP don't apply.

Third-party requests run in Electron's main process via a secure IPC bridge, where browser CORS and content-security policies don't bind. Call CRMs, webhooks, and databases directly from your companion code.

Fully isolated session.

The LOS runs in its own persistent Chromium partition, keeping its authentication completely separate from the user's personal browser — and from every other app on the machine.

Any platform, one config.

Zero hardcoded LOS specifics. Add URL patterns with named capture groups to a single config file — layout, context tracking, overlays, and telemetry all key off it.

A starting point, not a finished product

This is a template to copy and build on — not an app you download and use today. It gives you the foundation: the dual-pane workspace, the parts that are annoying and fragile to get right against a hostile SPA, and a clean IPC architecture. What you build on top is yours to decide: CRM sync, video rooms, checklists, dashboards, custom workflows.

Clone or copy the repo and run npm install · npm start. Electron is the only dependency.

Configure your LOS in config.js: URL patterns with named capture groups for the active record ID and tab. Launch via the built-in launchpad.

Verify against the mock LOS included in the repo — it simulates SPA routing and session storage so you can develop offline before touching production.

Build your features. Wire the declarative button config, the contextBridge APIs, and the main-process message hub to whatever your workflow needs.
